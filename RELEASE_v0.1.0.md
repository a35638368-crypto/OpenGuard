# OpenGuard v0.1.0 Release

## Overview

OpenGuard v0.1.0 is the first public release of a lightweight open-source server security scanner.

## Features

- Command-line security auditing workflow
- SSH configuration checks
- Port exposure detection
- Firewall status checks
- Markdown security reports
- JSON output support
- Automated tests and CI workflow

## Engineering

This release establishes the foundation for future security modules, including:

- Docker security checks
- Vulnerability database integration
- Extended report formats
- Additional security rules

## Getting Started

```bash
pip install openguard
openguard scan
```
