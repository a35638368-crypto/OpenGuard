# OpenGuard v0.1.0

## Initial Release

OpenGuard is a lightweight open-source server security scanner designed for developers and small teams.

## Features

- SSH configuration auditing framework
- Port exposure checks
- Firewall status checks
- Security report generation
- Extensible check architecture
- Command line interface

## Engineering

- Python package structure
- Automated testing support
- GitHub Actions workflow
- Contribution guidelines

## Roadmap

Future releases will add:

- JSON report output
- Docker security checks
- More security rules
- Additional integrations
