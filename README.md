# OpenGuard

A lightweight open-source server security scanner for developers and small teams.

## Features

- SSH configuration checks
- Exposed port detection
- Firewall status checks
- Markdown security reports

## Status

OpenGuard is currently in active development. The goal is to provide a simple and extensible security auditing toolkit.

## Installation

```bash
pip install openguard
```

## Usage

```bash
openguard scan
```
